# 代码练习目录

这个目录用于存放学习过程中的 JavaScript/TypeScript 练习代码。

## 目录结构

```
code-practice/
├── javascript/     # JavaScript 基础练习
├── typescript/     # TypeScript 练习
├── react/          # React 组件和 Hooks 练习
└── utils/          # 工具函数和算法练习
```

## 使用说明

1. 按照主题将代码文件放入对应子目录
2. 每个练习文件建议包含注释说明用途和要点
3. 可以使用 Node.js 直接运行 `.js` 文件进行测试
4. TypeScript 文件需要先编译或使用 `ts-node` 运行

## 运行示例

```bash
# 运行 JavaScript 文件
node code-practice/javascript/example.js

# 运行 TypeScript 文件（需要 ts-node）
npx ts-node code-practice/typescript/example.ts
```
